## Ориентиры
- Меня зовут Денис Евстигнеев. Со мной на "Ты". 
- Общаться с пользователем по-русски. Он проектировал ВЧ-аналоговые тракты
  с цифровым формированием импульса; это его первый аудиофонокорректор.
  Объяснять назначение аудиоузлов через схемотехнику и расчёт.
- Основная схема KiCad — `PreAmp.kicad_sch`; `PreAmp.net` — экспортированный
  снимок, который может отставать от редактора. LaTeX-схемы — в `docs/latex/`.
- Фактические соединения проверять по актуальному KiCad, расчётные номиналы —
  по `scripts/config.toml`. Автоматической синхронизации KiCad, TOML и TeX нет.
- Python-окружение живёт в `scripts/.venv`, зависимости — в
  `scripts/pyproject.toml`, конфигурация — в `scripts/config.toml`.
  Генерируемые результаты сохранять в корневой `build/`.
- Не менять написание существующих файлов `ballanced_in.kicad_sch` и
  `ne5532_ad3600l_ballanced.tex` без проверки всех ссылок. Головка — AT-3600L.
- Основной вариант: балансный вход, три корпуса NE5532 на стерео,
  обычные линейные выходы, питание ±12 В. Старый небалансный вариант
  сохраняется отдельно для сравнения.
- Не превращать расчётную АЧХ в утверждение о реально измеренных шуме,
  искажениях, устойчивости или CMRR. Границы модели описаны в контексте.
- Даташиты уже находятся в `docs/datasheet/`; сначала смотреть их.
- Замечания из REVIEW.md не считать исправленными без проверки файлов.
  При изменениях обновлять состояние в документах передачи контекста.
- Предыдущая просьба о подробном руководстве подразумевала отдельный документ
  без переработки существующих схем. Сохранять исходные варианты и не
  перерисовывать их попутно с документацией.
- ./docs/handoff/context
  * CONTEXT.md -- решения, номиналы, история проекта и оставшиеся задачи.
  * REVIEW.md -- проверка нетлиста и открытые замечания
  * WORKFLOW.md -- команды расчёта, сборки и продолжения сессии.
  * AGENTS.md -- инструкции будущему Codex прочитать этот контекст.
  Далеее все решения, планы по архитектуре пишем в ./docs/handoff/
- В ./docs/datasheet/ лежат нужные для схемы datasheets. Если там чего-то не хватает, скажи пожалуйста
- В директории ./out/ лежат сокращённые варианты netlist схемы, предназначенные
  для быстрого анализа и разбора схемы.
